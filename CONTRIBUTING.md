# Contributing to Aether

Aether is built collaboratively under an explicit 4-role model (Director / Architect / Implementer / Merge gate). The full operating manual — branching, tagging, self-review template, decision-recording, and accumulated gotchas — lives in [CLAUDE.md](./CLAUDE.md).

Architectural decisions live in [DECISIONS.md](./DECISIONS.md). The roadmap for each architectural arc lives in `docs/*-roadmap.md`.

External contributors: open an issue first to discuss scope before opening a PR. Aether is pre-1.0 and under active rearchitecture; coordination matters.
