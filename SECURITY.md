# Security Policy

## Supported Versions

Aether is pre-1.0 and under active development. Only the latest tagged release receives any security attention; earlier versions are not supported.

| Version       | Supported          |
| ------------- | ------------------ |
| Latest tag    | :white_check_mark: |
| All others    | :x:                |

## Reporting a Vulnerability

If you find a security issue, email ashwinsreedhar2003@gmail.com with details. Please do not open a public issue.

You can expect an acknowledgment within a few days. Aether is a single-developer project at this stage, so response and fix timelines are best-effort.

If the report is accepted, a fix will land in `main` and ship in the next tagged release. If declined (e.g. out of scope, intentional behavior), you'll receive a brief explanation.
