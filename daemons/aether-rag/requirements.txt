# aether-rag spike runtime deps — locked stack (CLAUDE.md lane: RAG CORE SPIKE).
#
# Two pins, deliberately minimal:
#   - fastembed: ONNX-backed embeddings, NO torch. Default model is
#     BAAI/bge-small-en-v1.5 (384-dim). The model ONNX weights (~130 MB)
#     are downloaded on first index into the fastembed HF cache, not vendored.
#   - sqlite-vec: loadable SQLite extension providing the vec0 virtual table
#     for KNN vector search. No server, no separate vector DB process.
#
# Transitive deps (onnxruntime, numpy, tokenizers, huggingface-hub, …) are
# resolved by fastembed; we pin only the stack choices the lane locked.
#   - mcp: the official Python Model Context Protocol SDK. server.py wraps the
#     retrieval core (rag_lib.search) as a stdio MCP server so every Claude
#     Code session in this repo inherits the corpus as a tool. The spike core
#     itself stays MCP-free — only server.py imports this.
fastembed==0.8.0
sqlite-vec==0.1.9
mcp==1.27.2
