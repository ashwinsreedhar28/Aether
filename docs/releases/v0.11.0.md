# Aether v0.11.0 — The Viewer Merge & the System That Staffs Itself

**Released:** 2026-06-11 · **Previous tag:** `v0.10.0` (2026-06-04)

> This cut also resolves the tag gap recorded in the Atlas and the v0.10.0
> notes: the `[0.10.0]` CHANGELOG section had existed since `#182` with no git
> tag behind it. `v0.10.0` is retro-tagged at the commit that introduced that
> heading (`28e35af`), and `v0.11.0` is tagged at this cut — the version story
> and the tag history agree again.

This is the release where Aether stopped being a cockpit you visit and became
the desktop you live in — and where the self-building loop stopped ending at a
draft on disk. Three arcs landed: **the Viewer merge** (one window manager, one
assistant, one mesh SDK), **the board as the only rail** (gaps file themselves
as GitHub issues), and **voice-spawned lanes** (accepted work staffs itself,
human-gated at every step).

---

## The arc

### The corpus, and the spawn actor

The week opened with the system growing a memory. A standalone RAG core over
Aether's own written record (`#184`) was wrapped as a stdio MCP server (`#187`)
so every implementer session inherits the corpus as a tool, and
**precedent-first implementers** became standing law (`#188`) — "how have we
solved this before?" is a retrieval now, not a guess. The **Atlas** arrived as
the living visual map of the whole system (`#190`), CLAUDE.md went on a diet to
stay under the performance threshold (`#198`), and the index learned to heal
its own staleness at boot (`#200`).

Rung 2 of the Architect arc went live the same week: the **spawn actor**
(`#192`) lets raven *request* an implementer spawn by voice — armed only by a
spoken passphrase, recorded on an append-only ledger, and nothing runs until a
human presses Approve on the card. v1.1 (`#199`) armed spawned sessions with
the corpus from birth and made the lifecycle honest.

### The Viewer merge

The defining arc. The 2026-06-09 capability-merge ADR (`#203`) set the plan:
the Viewer's window manager becomes Aether's shell, Raven becomes the only
assistant, the scene server retires in place for the AVP track. The lanes
executed it — the dormant Claude-SDK palette removed and the console
de-branded (`#205`), the duplicate mesh SDK collapsed onto
`@aether/mesh-node-sdk` (`#209`), the scene server, Leap remnants, and the
Dashboard-era voice tools retired (`#215`), CI taught to gate integration
trunks (`#213`) — and the merge landed (`#238`).

Voice caught up with the new body. `arrange_windows` gave raven real hands on
the layout, and `open_app` learned fuzzy app-name resolution (`#245`, `#307`);
**barge-in** made it interruptible (`#240`/`#242`); **session resumption**
made it survive Gemini's server-side socket kills (`#236`, after the model
migration in `#216`); **soft mute** stopped the mute button from killing the
session (`#306`). The post-arc docs refresh and the viewer-arc retrospective
banked the story (`#251`), the app icon went to v4 (`#252`), and the Atlas was
redrawn against the merged main (`#254`).

### The board becomes the rail

The gap ledger left the filesystem and moved onto the public record. A new
`github` Actor node (`#264`) gave the mesh `create_issue` / `list_issues` /
`comment_issue` with dedup built in — a repeat ask lands as a +1 comment, not
a duplicate. The Gaps panel was rewritten to read the live issue board
(`#269`), and raven's `report_gap` became a voice-gated two-turn filing flow
(`#270`) — at which point the `intents` node, the original JSONL gap ledger,
**retired entirely**: package, manifest entry, five edges. Gaps are issues
now; the board is the only rail; gaps close via the merge rail.

### Lanes spawn by voice

The loop's last manual hop fell. `work_on_issue` (`#298`) turns "work on issue
N" into a spawned implementer lane: the issue is fetched over the mesh, the
ARCHITECT SPEC marker is the guard (`#301`), and one approval card spawns the
lane — worktree, tmux-detached Claude Code session, terminal attached, tile
applied. Multi-issue utterances become one card; up to three lanes run at
once; quit leaves them running and boot offers reattach. The rail was then
hardened end to end (`#302`), and every lane's spawn card became summonable —
click its Lanes row or ask by voice (`#308`).

The loop now runs `gaps → issues → proposals → specs → spawned lanes → PRs`,
and a human gates every spawn and presses every merge.

## Upgrade / run

No migration steps. Pull `main`, then from the repo root:

```sh
pnpm install
pnpm -r build
cd shell && pnpm dev
```

Two optional capabilities gained env vars this release, both set by name in
`.env.local`: the gap board needs `AETHER_GITHUB_TOKEN` (a fine-grained PAT
with Issues read/write; `AETHER_GITHUB_REPO` overrides the default target
repo), and spawn lanes prefer `tmux` on the PATH (`brew install tmux`; a pty
fallback covers its absence). Everything else runs without them.

See the [README quickstart](../../README.md#quickstart) for prerequisites and
the `.env.local` notes. Full per-PR detail is in
[CHANGELOG.md](../../CHANGELOG.md).
