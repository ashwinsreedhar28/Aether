# Aether v0.12.0 — The Closed Loop

**Released:** 2026-06-11 · **Previous tag:** `v0.11.0` (2026-06-11)

> This is the first cut rolled by machinery instead of by hand: the
> `[0.12.0]` CHANGELOG section was compiled from ten per-lane fragments by
> `scripts/roll-changelog.mjs` (#222's contract), and DECISIONS.md is now a
> generated index over one-ADR-per-file. The record-keeping that used to make
> parallel lanes collide is itself part of what this release shipped.

v0.11.0 ended with lanes that spawn by voice and stop at a gate only a tmux
pane could see. This release closed the loop: the gate report travels to the
lane's own issue thread, the go-ahead rides back by voice, a reviewer cell
verdicts every PR against its ratified spec, the Director presses the button,
and the teardown happens by voice too. The whole circuit ran end to end on
issue #324 — gap filed by voice, spec drafted by the machine, ratified by a
human, lane spawned by voice, gate report on the thread, "clean, proceed"
relayed, reviewer verdict on the true head, merge, voice closeout. The
[self-building-arc retro](../retros/2026-06-self-building-arc.md) named the
next organs at the end of the v0.11.0 shakedown — "report ingestion, a
reviewer cell on the PR path, spec composition from the corpus." All three
landed here, built by the rail they extend.

## The arc

### The gate travels to the board

Rung 2.5 (`#315`) made the lane's GitHub issue thread the machine-readable
lane channel: every spawned lane posts its full gate report to its own issue
(`GATE REPORT — ` prefix) before stopping, and `PR OPENED — #N` the moment its
PR is up. The spawn card folds that thread **pull-based** — one
`github.get_issue` read on card open plus an explicit REFRESH, over a new
`shell → github.get_issue` edge, no background poller — into LANE AT GATE with
the report inline. The go-ahead became a voice act: `lane_proceed`
(confirm-gated) appends a `kind:"relay"` line to the spawn ledger, and the
shell enforces a v1 allowlist of exactly one utterance — the literal
`clean, proceed` — typed into the lane's pane over the proven pane-id
machinery. Boot-pending relays are failed by name, never auto-sent.

### A reviewer joins the PR path

The reviewer cell (`#314`) sits on every PR to a trunk:
`.github/workflows/claude-spec-review.yml` resolves the Closes-issue, reads
the ratified ARCHITECT SPEC (+ ADDENDUM comments), and reviews the diff
against FIX / SMOKE / OUT-OF-SCOPE — posting exactly one verdict comment per
head SHA, superseded in place: `REVIEWER: APPROVE`, `REVIEWER: CONCERNS —`
itemized, or `REVIEWER: NO SPEC FOUND` (a spec-less PR is never approved).
`#323` pinned the verdict to the **head commit SHA** — the prompt receives
`HEAD_SHA` explicitly and blob SHAs from API payloads are forbidden, so the
supersede contract keys on a real commit. The verdict is advisory by design:
the merge condition is CI green + `REVIEWER: APPROVE` + the Director's
button, and promoting it to a required check is an autonomy-ladder decision
(A2) deliberately not taken.

### The composer's maiden flight

Rung 1.5 (`#319`) gave the loop a drafting hand:
`daemons/architect-draft/compose_spec.py` takes a gap issue, retrieves
precedent from the local corpus (importing `rag_lib`, the primitive
`search_corpus` wraps), prompts the **Director-configured** draft model
(`AETHER_DRAFT_MODEL` → `architect/config.json`; no default in code —
unconfigured is an instructive refusal), and posts the result prefixed
`DRAFT SPEC (machine-composed, unratified) — `. The load-bearing guard:
any line that would anchor the spawn gate's spec marker is
blockquote-defanged, and a body that still matches is hard-refused — a
machine draft can never self-certify a lane; ratification stays a human
re-posting the real marker. The composer is an out-of-mesh actor on the PAT
REST contract, triggered by voice via `draft_spec(number)`. Its maiden flight
drafted the spec that became #324's lane — the first link in the first full
loop.

### Teardown by voice, truth about orphans

`close_lane` (`#320`) is the spawn's mirror: a `kind:"teardown"` ledger
request whose execution — kill-session, kickoff cleanup, submodule deinit,
worktree remove, branch delete, submodule restore — runs behind ordered
guards: an open PR on the branch refuses outright, a busy pane refuses
outright, and a dirty worktree or unpushed branch warns into an explicit
CLOSE ANYWAY. `closed` is written only after every step succeeds; a failed
step lands as `teardown_failed` with a retry card. And the orphan list
stopped lying (`#321`): reattach rows backed by live records carry COMPLETE
with full warn-and-force semantics, and the list became a pull-refreshed
cache — dead sessions drop from every strip without a relaunch.

### The record learns to keep pace

The two shared append surfaces stopped being rebase magnets (`#327`): lanes
write ONE fragment under `changelog/unreleased/` and land decisions as
ADR-per-file under `decisions/`; CHANGELOG.md's `[Unreleased]` body and
DECISIONS.md are generated, and the auto-review flags hand-edits. This cut is
that machinery's first real run. The field-gotcha bank (`#326`) banked four
§10-class gotchas from the organ-building arc, and the lane terminal learned
to scroll its buffer instead of its history (`#328` — tmux mouse mode per
lane session, the fix #324's loop shipped).

## Upgrade / run

No migration steps. Pull `main`, then from the repo root:

```sh
pnpm install
pnpm -r build
cd shell && pnpm dev
```

One optional capability gained config this release: the Rung 1.5 composer
needs a draft model configured by name — env `AETHER_DRAFT_MODEL` or
`draft_model` in `<data-root>/architect/config.json` (no default exists in
code; unconfigured, `draft_spec` refuses with the knob's name) — plus its
own venv per `daemons/architect-draft/README.md`. The reviewer cell runs
CI-side and needs nothing locally. Everything else is as v0.11.0:
`AETHER_GITHUB_TOKEN` for the board, `tmux` on the PATH for lanes.

See the [README quickstart](../../README.md#quickstart) for prerequisites and
the `.env.local` notes. Full per-PR detail is in
[CHANGELOG.md](../../CHANGELOG.md).
